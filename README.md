# Blanqueria Mauri Gestion

Aplicacion independiente para gestionar inventario, ventas y clientes de Blanqueria Mauri.

## Desarrollo

Instalar dependencias:

```bash
npm install
```

Ejecutar la app:

```bash
npm run dev
```

Vite mostrara la URL local para abrir en el navegador.

## Persistencia actual

En esta etapa la aplicacion mantiene la funcionalidad original y sigue guardando los datos en `localStorage` del navegador. La conexion a Supabase se agregara en una etapa posterior.
